Proyecto / 01

Pricing y canasta de supermercado

Pregunta de negocio: ¿qué cadena conviene al comparar productos equivalentes? Con Python, DuckDB y SQL procesé 97,5 millones de precios. En el índice del último día comparable, Carrefour marcó 96,98 y Jumbo 103,36 sobre 634 GTIN comunes. En una medición separada, la canasta costó $29.109 en Vea y $34.272 en HiperChangomas: una brecha de $5.163 (15,1%).

Proyecto / 02

Analytics de clientes e-commerce

Pregunta de negocio: ¿dónde se concentra el GMV y cómo cambia la experiencia de entrega? Con DuckDB y SQL segmenté 93.358 clientes; el grupo A concentró 80,6% del GMV y la review ponderada fue 4,29 a tiempo frente a 2,57 tardía, una relación descriptiva.

Dashboard ↗ Release / PBIX ↗ Repositorio ↗
Proyecto / 03

Pulso del retail argentino

Pregunta de negocio: ¿el crecimiento observado fue real o principalmente nominal? Con Python/pandas, SQL Server y Power BI separé ambas lecturas. En supermercados: +25,9% nominal interanual y -0,7% real interanual. En autoservicios mayoristas: +23,7% nominal interanual y -2,3% real interanual.
