# Portfolio de Alexander Huth

Sitio personal orientado a mi perfil profesional como Data Analyst.

Presenta casos reproducibles de retail argentino, pricing de supermercado y clientes
e-commerce, con enlaces a sus repositorios y entregables tecnicos.

## Tecnologias

- HTML5
- CSS3
- JavaScript sin dependencias

El diseno utiliza una interfaz editorial oscura, una reticula tecnica y capturas reales
de los dashboards publicados. Es responsive y respeta las preferencias de movimiento
del sistema.

Los avisos de licencia de los iconos del footer se encuentran en
[`assets/icons/LICENSES.md`](assets/icons/LICENSES.md).

El sitio se publica con GitHub Pages en [alexanderhuth98.github.io](https://alexanderhuth98.github.io/).
