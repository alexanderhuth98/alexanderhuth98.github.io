# Portfolio de Alexander Huth

Sitio personal orientado a oportunidades como Data Analyst Jr. Combina experiencia
operativa real en retail desde 2020, incluido el rol actual de vendedor/preventista desde
marzo de 2026, con proyectos reproducibles de análisis de datos.

Presenta tres casos públicos de pricing de supermercado, clientes e-commerce con Olist y
retail argentino. Cada caso parte de una pregunta de negocio, documenta su método y expone
hallazgos, controles de calidad y limitaciones sin atribuir impacto comercial real.

El perfil mantiene los datos verificables del CV: 13 de 21 materias promocionadas en la
UNaB, inglés B2 y disponibilidad full time.

El [CV público](assets/cv/alexander-huth-data-analyst.pdf) está disponible desde la
navegación y el bloque principal del sitio.

## Tecnologías

- HTML5
- CSS3
- JavaScript sin dependencias

El diseño utiliza una interfaz editorial oscura, una retícula técnica y capturas reales
de los dashboards publicados. Es responsive y respeta las preferencias de movimiento
del sistema. Incluye metadata Open Graph/Twitter y una imagen social propia de 1280 x 640.

Los avisos de licencia de los íconos del footer se encuentran en
[`assets/icons/LICENSES.md`](assets/icons/LICENSES.md).
